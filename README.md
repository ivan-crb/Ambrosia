# Ambrosia

Ambrosia is a modern, smart meal planner for Android designed to simplify your weekly cooking and shopping experience.

## Features
- **Dynamic Meal Planning**: Customize your meal schedule with fully flexible slots (Breakfast, Lunch, Dinner, Snacks). Add or remove slots to fit your daily routine.
- **Smart Shopping List**:
  - **Global Category Learning**: Ambrosia remembers how you categorize your ingredients. Update a category once, and it automatically syncs across all recipes and lists.
  - **Intelligent Grouping**: Automatically group items by category (Produce, Dairy, Meat) or sort them alphabetically.
  - **Inline Inventory**: Track pantry items directly from your shopping list so you never double-buy.
- **Recipe Discovery & Management**: Organize your cookbook using custom tags (e.g., *Vegetarian*, *Quick*, *Cheap*) and find meals instantly using the built-in search bar.
- **Plan Templates**: Save your favorite weekly meal plans as reusable templates and apply them to future weeks with a single tap.

## Getting Started

### Prerequisites
- Android device running **Android 15 (minSdk 35)** or higher.
- [Android Studio Ladybug](https://developer.android.com/studio) or newer for building from source.

### Installation
1. Download the latest `.apk` from the [Releases](https://github.com/IvanCM/Ambrosia/releases) page.
2. Install the APK on your Android device (ensure "Install from unknown sources" is enabled).

### Building from Source
```bash
git clone [https://github.com/IvanCM/Ambrosia.git](https://github.com/IvanCM/Ambrosia.git)
cd Ambrosia
./gradlew assembleRelease
